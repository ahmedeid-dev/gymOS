> كل ما تحتاجه لإدارة المشتركين، حضور الموظفين والكباتن، والاشتراكات في شاشة واحدة سهلة وسريعة.

هل تعاني من مشاكل تسجيل المشتركين بالدفاتر، عدم انضباط مواعيد الكباتن، أو ضياع تفاصيل الاشتراكات وتجديدها؟  
**GymPro ERP** تم تطويره ليحل كل هذه التحديات بشكل عملي وسريع:

---

## 🚀 المميزات والحلول التي يقدمها النظام

### 1️⃣ صفحة استقبال عامة احترافية (Landing Page)
- واجهة راقية لتعريف زوار ومترددي الجيم بخدمات الصالة والكلاسات المتاحة.
- عرض خطط الأسعار والاشتراكات المتاحة للجمهور بشفافية.
- إمكانية التواصل المباشر مع إدارة الجيم وتحديد الموقع بسهولة.

### 2️⃣ كشك تسجيل الحضور الذكي بالاستقبال (Front-Desk Kiosk)
- **شاشة تابلت سريعة عند باب الدخول**:
  - **للمشتركين (اللاعبين)**: تسجيل حضور فوري بكود العضوية أو برقم الهاتف في ثانية واحدة لمنع التكدس بالاستقبال.
  - **للكباتن وموظفي الاستقبال والصيانة**: تسجيل "حضور" عند بداية الوردية وتسجيل "انصراف" عند نهايتها لمنع التلاعب وتحديد ساعات العمل الفعلية.
  - **ساعة إلكترونية مباشرة**: تعرض الوقت الفعلي وتاريخ اليوم لتوثيق توقيت الدخول والخروج بدقة.
  - **سجل فوري**: يوضح آخر الأشخاص الذين سجلوا دخولهم في نفس اللحظة.

### 3️⃣ نظام متكامل لإدارة حضور وغياب الموظفين والكباتن (داخل الداشبورد)
صفحة رقابية مخصصة للإدارة ومدير الجيم لمتابعة التزام الفريق بدقة:
- ⏰ **حساب التأخيرات التلقائي**: معرفة الموظف أو الكابتن المتأخر بالدقيقة بناءً على موعد بداية شفته.
- 🌙☀️ **نظام الشفتات (نهاري / ليلي)**: إدارة مرنة لمواعيد العمل (ورديات صباحية ومسائية).
- 📋 **متابعة الحالات التفصيلية**:
  - الحاضرون الآن في الصالة.
  - المتأخرون مع سبب التأخير.
  - الغائبون بدون إذن.
  - الإجازات السنوية والرسمية.
  - الإجازات المرضية المعتمدة.
  - أذونات الخروج والاستئذان المؤقت خلال اليوم.
- 📝 **إضافة وتوثيق الإجازات والأذونات**: إمكانية تسجيل إجازة أو إذن لأي موظف مع كتابة السبب والمدة ليتم خصمها أو احتسابها تلقائياً.

### 4️⃣ إدارة المشتركين والعضويات (Members CRM)
- تسجيل بيانات الأعضاء الجدد، أرقام تواصلهم، وتاريخ انضمامهم.
- متابعة فورية لحالة كل اشتراك:
  - 🟢 **نشط (Active)**: الاشتراك سارٍ ويمكنه الدخول.
  - 🟡 **يوشك على الانتهاء (Expiring)**: لتذكير العميل بالتجديد في الوقت المناسب ومتابعة المبيعات.
  - ⚪ **مجمد (Frozen)**: للأعضاء الذين طلبوا تجميد اشتراكهم لفترة معينة.
- إحصائيات بعدد مرات زيارة ودخول كل لاعب للمتابعة وقياس مدى التزامه.

### 5️⃣ نظام أمان وتسجيل دخول متطور (Multi-Role Auth)
- تسجيل دخول آمن لإدارة الجيم.
- دعم الدخول بنقرة واحدة بحساب **Google**.
- ميزة استعادة كلمة المرور عبر البريد الإلكتروني في حال نسيانها.
- إمكانية فتح حسابات مختلفة حسب الوظيفة (عضو، كابتن، موظف استقبال، مدير).

### 6️⃣ دعم كامل للغة العربية والإنجليزية (RTL / LTR)
- واجهة مستخدم عربية بالكامل تناسب موظفي الاستقبال والكباتن في مصر والوطن العربي مع دعم التبديل للإنجليزية بضغطة زر.

## 🖥️ متطلبات وطريقة تشغيل النظام (للمطورين وفرق الدعم)

النظام مبني بأحدث التقنيات الحديثة لضمان السرعة الفائقة والأمان الكامل:
- **الواجهة الأمامية**: React 19 + TypeScript + Material UI (MUI v7)
- **إدارة البيانات والربط**: Redux Toolkit
- **دعم اللغات**: i18next (عربي/إنجليزي)

### خطوات التشغيل السريع:
```bash
# تثبيت الحزم المطلوبة
npm install

# تشغيل بيئة العمل التجريبية
npm run dev

# تجهيز النسخة النهائية للإنتاج
npm run build
```
